# SANTOS SA1 — Linear Models

## Files
- `code/SANTOS_SA1.R` — reproducible R analysis script.
- `data/SANTOS_SeoulBikeData.csv` — UCI Seoul Bike Sharing Demand dataset.
- `report/SANTOS_Report.pdf` — report with computed results, plots, tables, model inference, diagnostics, validation, and conclusions.
- `output/figures/` — generated EDA plots.
- `output/tables/` — CSV tables and diagnostic summaries.

## Run
Open the project root in R/RStudio and run `source("code/SANTOS_SA1.R")`. The script creates figures and tables under `output/`. It installs required R packages if missing.

## Dataset
UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand
